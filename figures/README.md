# Figures

This directory is reserved for publication figures generated by the experiment scripts.

Large or temporary generated files should not be committed. Keep only figures that are intentionally versioned for reproducibility or the paper.

Recommended figure groups:

- centralized SOM timelines;
- feature-analysis plots;
- FedAvg convergence curves;
- dropout comparisons;
- reliability stress-test comparisons;
- reliability-aware aggregation diagnostics.
